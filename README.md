# atomcamp Agentic AI (Cohort 5)

My work and notes from atomcamp's Agentic AI course (Cohort 5), built in public.

I am a materials engineer moving into data and AI, so I frame every exercise the
way a materials informatics engineer would: the same programming skills, pointed at
materials data, properties, and the pipelines that tie them together.

## Weeks

- [Week 1: Python fundamentals](week-01-python-fundamentals/) - basics through
  functions, loops, conditionals and dictionaries. Includes a menu-driven Grade
  Management System, then the same dictionary operations extended to a materials
  example (materials mapped to their Young's modulus).
