Week 2 of atomcamp's Agentic AI cohort is done. Here is what I learned, and what I built with it.

What I learned

This week was about giving language models tools and memory. I went deep on RAG and how it differs from plain semantic search, embeddings and vector databases, loading data from PDFs, SQL, web pages and text files, HuggingFace models, Spaces and embeddings, LangChain and LangGraph and when to use each, API keys and providers like OpenAI, Groq and RapidAPI, Gradio, and the history of transformers and NLP that started all of this.

A lot for one week. But it only stuck because I built something with it.

What I built

A Materials Research Assistant. One agent, six tools, and it decides which to use for each question:

- search many materials databases at once (Materials Project, OQMD, COD, Alexandria) through the OPTIMADE standard
- pull the deep properties of a specific material from the Materials Project
- find recent papers on arXiv
- answer questions about a PDF you upload, using RAG
- convert materials units with a custom Python function
- fall back to a web search when nothing else fits

The part I am proud of: the first tool finds materials across every major database with one query, and when the agent needs the deep numbers, it hands that material straight to the Materials Project tool. Broad find, then deep dive.

The lesson of the week, in one line: an agent is only as good as its tools and its data. The model is not the clever part. Choosing the right tool and feeding it clean, relevant context is.

That is a very materials-data way to see it, which is exactly why I keep pointing these exercises at materials problems.
